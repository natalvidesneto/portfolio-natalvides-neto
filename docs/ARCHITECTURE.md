# 🏗️ Arquitetura do Projeto

Este projeto segue uma arquitetura front-end moderna baseada em:

• Vite como bundler
• JavaScript modular (ES Modules)
• CSS integrado ao pipeline
• Bootstrap via npm

## 📦 Camadas

* `index.html` → Estrutura semântica
* `js/main.js` → Entry point
* `js/modules/` → Lógica separada por responsabilidade
* `css/styles.css` → Estilos customizados
* `.env` → Configurações sensíveis

## 🎯 Objetivo da Arquitetura

• Código limpo
• Escalável
• Fácil manutenção
• Padrão de mercado
