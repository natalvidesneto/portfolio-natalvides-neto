# 🤝 Contribuindo

Este projeto segue padrões profissionais.

## ✔️ Padrões

• Conventional Commits
• ESLint + Prettier
• Branches:

* main → produção
* develop → desenvolvimento

## 📌 Commits

Exemplos:

feat: add whatsapp form integration
fix: correct css pipeline with vite
build: configure eslint and prettier

---

Contribuições devem seguir:

1. Criar branch a partir de `develop`
2. Commitar com padrão
3. Abrir PR para `develop`
